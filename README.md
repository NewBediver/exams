# Вступительные экзамены в аспирантуру по специальности 2.3.5

Материалы для подготовки к вступительным экзаменам в аспирантуру по научной специальности **2.3.5 «Математическое и программное обеспечение вычислительных систем, комплексов и компьютерных сетей»**.

Репозиторий объединяет вопросы из программ **ИТМО**, **СПбГУ** и **СПбПУ**. Близкие по содержанию формулировки разных университетов сведены в общие билеты, для которых подготовлены развёрнутые ответы в LaTeX.

> [!IMPORTANT]
> Это неофициальные учебные материалы. Программы и правила приёма могут меняться — перед подготовкой сверяйтесь с актуальными документами выбранного университета.

## Содержание репозитория

- **91 сводный билет** с ответами в LaTeX;
- матрица соответствия вопросов трёх университетов в [`list.xlsx`](list.xlsx);
- 12 тематических конспектов по программам ИТМО и СПбГУ — по 6 файлов на университет;
- вспомогательные PDF-источники для отдельных тем;
- определения, теоремы, доказательства, алгоритмы, примеры и сравнительные таблицы.

Все содержательные строки сводного списка обеспечены билетами. Пропуски в нумерации каталогов сделаны намеренно: номера **1, 2, 20, 30, 49, 64, 71, 83 и 93** соответствуют заголовкам таблицы и тематическим разделам в [`list.xlsx`](list.xlsx), а не экзаменационным вопросам.

### Сводная таблица

[`list.xlsx`](list.xlsx) — источник нумерации и карта соответствия программ:

- столбец **A** — ИТМО;
- столбец **B** — СПбГУ;
- столбец **C** — СПбПУ;
- одна строка объединяет близкие по содержанию вопросы разных университетов;
- пустая ячейка означает, что в программе соответствующего университета нет отдельного вопроса с такой формулировкой.

### Университетские конспекты

Каталоги [`ITMO/`](ITMO/) и [`SPbU/`](SPbU/) содержат последовательные конспекты по разделам официальных программ. Несмотря на расширение `.txt`, внутри используется Markdown-разметка и формулы LaTeX.

### Сводные билеты

Каждый каталог `card_<номер>/` соответствует строке с экзаменационным вопросом в [`list.xlsx`](list.xlsx). В заголовке `answer.tex` перечислены формулировки университетов, вошедшие в билет. Номер каталога — номер вопроса в сводной таблице, а не номер билета конкретного университета.

## Как пользоваться

### Найти нужный вопрос

1. Откройте [`list.xlsx`](list.xlsx).
2. Найдите формулировку в столбце своего университета.
3. Запомните номер строки, например `44`.
4. Перейдите в `card_44/answer.tex`.

Для поиска по ключевым словам также можно использовать поиск GitHub по репозиторию.

### Читать исходный ответ

Откройте нужный файл `answer.tex` на GitHub. Ответы разбиты на разделы и подразделы и включают математические формулы, определения и примеры.

### Собрать билет в PDF

Для локальной сборки понадобится дистрибутив LaTeX с поддержкой русского языка, например TeX Live. Все файлы `answer.tex` собираются с помощью `pdflatex`:

```bash
pdflatex -synctex=1 -interaction=nonstopmode -file-line-error -recorder "/home/vlad-serikov/phd/exams/card_5/answer.tex"
```

Для другого билета замените `card_5` на номер нужного каталога. Результат сборки — файл `answer.pdf`.

## Рекомендации по подготовке

Материалы предназначены для систематизации знаний, а не для механического заучивания. Рекомендуется:

- начать с официальной программы выбранного университета;
- использовать [`list.xlsx`](list.xlsx) как навигатор по билетам;
- проверять определения и формулировки теорем по учебникам и первоисточникам;
- самостоятельно разбирать доказательства, алгоритмы и примеры.
